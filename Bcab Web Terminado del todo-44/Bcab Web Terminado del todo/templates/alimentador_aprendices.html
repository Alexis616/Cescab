Alimentar Tabla de Aprendices

Campos disponibles en la tabla Aprendices:

  • idAprendiz - ID del aprendiz
  • tipoDocumento - Tipo de documento
  • numeroDocumento - Número de documento
  • ficha - Número de ficha
  • nombres - Nombres del aprendiz
  • apellidos - Apellidos completos (usar si vienen juntos)
  • apellido1 - Primer apellido (se concatenará con apellido2)
  • apellido2 - Segundo apellido (se concatenará con apellido1)
  • telefono - Número de teléfono
  • correo_electronico - Correo electrónico
  • estado - Estado del aprendiz
  • juicio - Juicio evaluativo
  • fechaInicio - Fecha de inicio
  • fechaFin - Fecha de finalización
  • medida_formativa - Medida formativa

📝 Nota sobre Apellidos:

Si los apellidos vienen separados en el CSV: Use "apellido1" y "apellido2" como campos - se concatenarán automáticamente en la base de datos.

Si los apellidos vienen juntos: Use directamente "apellidos" como campo.
